# An explaination on Inheritance and genetic and how it contribute to good game Design
For any good programming design there are bound to be loads of classes
used in the running of the program and for the programmer having to
write all of them it can lead to a problem relating to redundacy and the need
to reuse the same class over even if the diffrence is superficial conversely
many of those class can be classfied in the same category. thus the usage of Inheritance
and genetic allows the programmer to reuse the a class called superclass in order
to place simlar class together and to make a hieracy of classes that allows for more
specialles classes by adding varible and methods.

for instance rather than writing each animal seperatlly, intsed by using the extend
function, we can make it so that the class uses the code from the super class instead
of duplicating the same code.
